API‑Narrativ

Der API‑Raum ist die Kommunikations‑Engine des DISpatchers.

Er verbindet:

• RAW → Kräfte
• RAM → Achsen
• ROM → Axiome
• core → DQF / RIR / KIT / 243 / XyX
• markt → Kapitalfluss / Risiko / Industrie / Börse
• index.html → UI

API ist der Vermittler zwischen allen Engines.

API‑Module

• ART.link
• flow.js

• respo-linker-engine.js

Jedes Modul hat eigene Parameter.

API‑Parameter

API.system unterstützt dynamische Parameter:

• apiMode        → "normal", "markt", "raw", "ram", "rom"
• apiFlow        → Flow‑Intensität
• apiImpulse     → Impuls‑Stärke
• apiAxiom       → d/e/i/n/o/r/s/w/u
• apiAxis        → 3/9/27/81/243/729
• apiTorque      → Kraft aus RAW.engine
• apiMarket      → Marktfluss aus market.js
• apiRAM         → Achsen‑Speicher aus RAM.engine
• apiROM         → Axiom‑Gesetze aus ROM.engine

Diese Parameter können dynamisch geändert werden.
